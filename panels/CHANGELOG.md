# panels: latest changes

Newest first. Generated by panel-sync.sh from the Home Deck commits.

## 2026-10-30 (3)

- The setup wizard's code field could not be typed into, so a fresh install could not get past its
  first screen. The handler was `e => e.key === 'Enter' && $('#go').click()`, and for every other key
  that arrow returns false; an onkeydown property handler that returns false cancels the keystroke.
  The field took a paste and the `?code=` link, which is why it was not obvious. Braced now, like the
  two other key handlers in the repository.
- tests/scripts.py checks that every key handler has a braced body. The file parses, the page renders
  and the handler fires, so nothing else would have noticed.

## 2026-10-30 (2)

- A fresh install from a clone stopped with
  `install: cannot stat '/tmp/tmp.XXXX/bin/homedeck-install-tree'`. The kit is built two ways -
  build_kit.sh for the published tarball, install.sh straight from a checkout - and they listed the
  files separately, so install.sh never staged homedeck-install-tree or either update unit. The kit
  build is the path that gets exercised; the clone is the path a stranger takes. install.sh stages
  all three now, and tests/install.py reads what install-homedeck.sh opens and fails if either
  builder leaves one out.

## 2026-10-30

- The Mac installer is gone. Home Deck installs on Debian, Ubuntu or a Raspberry Pi with
  installers/linux/setup.sh; installers/README.md says what to do with only a Mac.
- The README follows the shape every project in this repository now uses: Screenshots,
  Features, Install, Use, How it is built, Notes. The folder table, which used to open the
  page with server names and addresses, has moved to How it is built, and the setup wizard's
  own screenshots now sit with the others. A Features list says what Home Deck does, which
  the README never said in one place before.
