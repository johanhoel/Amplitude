Home Deck setup

Connect the panels to your Home Assistant. Takes about two minutes.

1Your Home Assistant

–
This is the address the installer saved. To change it, edit [homeassistant] url in the panel editor.

2Make a token in Home Assistant

  1. Open your Home Assistant profile → Security (log in as an administrator).
  2. Scroll to Long-lived access tokens → Create token, name it Home Deck.
  3. Copy the long code it shows (it is shown only once) and paste it below.
The token is kept privately on this server and never shown on the panels.
